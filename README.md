# CarDekho Car Price Analysis

## Project Overview

This project analyzes used car data to understand car pricing trends and identify factors affecting selling prices. The analysis was performed using Python for Exploratory Data Analysis (EDA) and Power BI for interactive dashboard creation.

## Objectives

* Analyze used car selling prices.
* Compare prices across fuel types and transmission types.
* Understand the relationship between car age and selling price.
* Analyze car brands and their price patterns.
* Explore the relationship between engine specifications, mileage, and selling price.

## Dataset

* **Source:** Kaggle
* **File:** `cardekho_dataset.csv`
* **Original Records:** 15,411
* **Features:** 14 columns

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Power BI

## Project Workflow

1. Loaded the dataset using Pandas.
2. Checked data types, missing values, and duplicate records.
3. Performed data cleaning and exploratory data analysis.
4. Analyzed car prices across different categories.
5. Created visualizations using Python.
6. Developed an interactive Power BI dashboard.

## Key Insights

* The average selling price was approximately ₹7.75 lakh.
* Automatic cars had a higher average selling price than manual cars.
* Maximum power showed a strong positive correlation with selling price.
* Maruti had the highest number of cars in the dataset, followed by Hyundai.

## Conclusion

This project helped identify patterns in used car prices and understand how vehicle characteristics are associated with selling prices. Python supported data analysis and visualization, while Power BI provided an interactive way to explore the results.
